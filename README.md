# Installation

```text
pkg update && pkg upgrade -y
git clone https://github.com/tepeed/vbv.git
pip install requests asyncio aiohttp faker colorama pyfiglet httpx pycryptodome distro
cd vbv
pip install -r requirements.txt
python vbv.py
```
